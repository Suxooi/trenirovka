# Журнал тренировок — приложение для телефона

Это веб-приложение (PWA). После публикации по ссылке его можно установить на экран «Домой»: оно открывается без адресной строки, со своей иконкой и работает без интернета.

## 1. Получить ссылку (GitHub Pages, бесплатно)

1. Зайдите на github.com → **New repository**. Имя, например, `trenirovki`. Тип — **Public**. Создайте.
2. На странице репозитория: **Add file → Upload files**. Перетащите **всё содержимое** этой папки (`index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, папку `icons`). Нажмите **Commit changes**.
3. **Settings → Pages**. В «Build and deployment» выберите **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты появится ссылка вида `https://ВАШ-ЛОГИН.github.io/trenirovki/`.

## 2. Установить на телефон

**iPhone (Safari):** откройте ссылку → кнопка «Поделиться» → **На экран «Домой»** → «Добавить».

**Android (Chrome):** откройте ссылку → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).

## Данные

Записи хранятся на самом телефоне. В разделе «Итоги» есть кнопки **Сохранить копию** и **Загрузить копию** — сохраняйте копию время от времени и переносите её этим же способом на новый телефон.

## Обновление

Замените файлы в репозитории новыми (версия в `sw.js` уже обновлена при сборке). Приложение подтянет обновление при следующем запуске с интернетом.

## База знаний тренера — `kb.json`

Единый источник знаний тренера: выводы позиций (ACSM, ISSN, ВОЗ), метаанализов и книг по тренировкам и питанию,
пересказанные своими словами, у каждого — источник. Приложение при запуске берёт свежую версию этого файла
(встроенная копия — запасная), навык «Фитнес-тренер» для Claude читает его отсюда же.

Формат: `{"v": номер версии, "updated": "ГГГГ-ММ-ДД", "items": [{"id","k","t","x","s"}], "log": [...]}`
— `k` слова для поиска, `t` заголовок, `x` суть (2–4 предложения), `s` источник (авторы, год, журнал/книга).
При каждой правке увеличивайте `v` и добавляйте запись в `log`. Раз в месяц база дополняется автоматически.
Тексты книг и статей не копируются — только выводы своими словами со ссылкой на источник.

## Распознавание штрихкодов

`vendor/zxing/` — zxing-wasm (сборка zxing-cpp, лицензия MIT): читает штрихкоды с камеры и фото,
в том числе на iPhone, где у Safari нет своего распознавателя. Файлы лежат в репозитории, поэтому
сканер работает без CDN и офлайн. Обновить версию — Actions → vendor-zxing → Run workflow.
